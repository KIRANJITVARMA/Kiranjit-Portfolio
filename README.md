# Kiranjit Varma — Animated Portfolio

A responsive animated developer portfolio featuring the supplied illustrated profile image.

## Files
- `index.html` — complete site (HTML/CSS/JS); the profile portrait is embedded so the file previews correctly on its own
- `assets/kiranjit-avatar.png` — original supplied profile portrait
- Project showcase includes FinWise AI, Study AI Assistant, and Career Pilot AI

## Preview
Keep the `assets` folder next to `index.html`, then open `index.html` in your browser.

## Publish
Upload both `index.html` and the `assets` folder to a static host such as GitHub Pages, Netlify, or Vercel. No build step is required.

## Note about Framer
This is a ready-to-preview, static implementation based on the details provided, not a site imported into your private Framer workspace. The supplied portrait is included as the hero image.
